## 🎯 Project Objective
The primary goal of TechCompass is to build an AI-powered platform that assists Software Engineering (SE) students in early career orientation, identifying missing skills, and generating highly personalized learning roadmaps based on real-world IT market demands.

## 📖 Context & Problem Statement
The Software Engineering field is vast and rapidly evolving. Students frequently face the following challenges:
1. **Skill Gaps:** Traditional university curricula often lag 2-3 years behind industry standards, teaching older frameworks while the market moves on.
2. **Choice Paralysis:** Students are overwhelmed by the abundance of generic "Roadmaps" online and struggle to find one that fits their specific academic background and interests.
3. **Disconnected Portfolios:** Students often build scattered, random projects that fail to tell a coherent "story" to potential employers.
4. **The "Generalist" Trap:** Many graduate knowing a little of everything but aren't job-ready for specialized, high-demand roles (e.g., Cloud Architect, Data Engineer).

**Primary Actors:** SE Students, Academic Counselors, Industry Mentors.

## ✨ Core Features & Functional Requirements

### 1. 🤖 AI Virtual Mentor
* **FR1.1:** Natural language chat interface for career-related queries.
* **FR1.2:** Integration with powerful LLMs (e.g., Gemini / GPT-4) to provide expert technical career advice.
* **FR1.3:** Context-aware responses generated by analyzing user-uploaded academic transcripts and public GitHub profiles.

### 2. 🗺️ Dynamic Learning Roadmap
* **FR2.1:** Selectable "Target Career Roles" (e.g., DevOps Engineer, Mobile Developer).
* **FR2.2:** Auto-generation of a hierarchical Skill Tree presenting technical nodes in a prioritized learning sequence.
* **FR2.3:** Curated learning resources (YouTube, Official Docs) attached to every technical node.
* **FR2.4:** Real-time progress tracking by marking nodes as "Completed".

### 3. 📊 Skill Gap Analysis
* **FR3.1:** Manual input or selection of current technical skills.
* **FR3.2:** Automated mapping analysis comparing current skills vs. Target Career Role requirements.
* **FR3.3:** Generation of visual reports (and exportable PDFs) highlighting missing skills and urgent learning priorities.

### 4. 📈 Market Pulse
* **FR4.1:** Automated daily data scraping from major IT job portals (LinkedIn, TopCV).
* **FR4.2:** Keyword frequency analysis on job descriptions to detect trending tech stacks.
* **FR4.3:** Interactive trend charts displaying the growth or decline in demand for specific skills.

### 5. 💼 E-Portfolio Management
* **FR5.1:** GitHub account linking and synchronization of public repositories.
* **FR5.2:** AI-driven extraction and summarization of project objectives and tech stacks directly from `README.md` files.
* **FR5.3:** Generation of a unique, shareable E-Portfolio URL to easily send to potential employers.

### 6. 🔐 User Management
* **FR6.1:** Secure authentication via Email/Password and Google OAuth 2.0.
* **FR6.2:** Persistent database storage for user chat history, skill assessments, and roadmap progress.

## 🏛️ Domain Architecture
The core system is built around the following main entities:
* `Student Profile`
* `Tech Path`
* `Skill Node`
* `Course Repo`
* `Job Trend`
* `Mentor Session`

## 🔬 Research Questions
This project actively explores the following academic/technical questions:
1. *How can AI identify a student's "latent talent" (e.g., logical thinking vs. UI/UX flair) through their coding patterns and historical data?*
2. *How effective is a dynamic roadmap that continuously updates based on real-time LinkedIn job trend analysis compared to static curricula?*
